# Erdős Problem 506

This directory contains the English and Chinese papers, the exact Python verification chain, and the Lean 4 formalizations for Erdős Problem 506. Install `computation/requirements.txt`, run `python computation/verify_all.py`, and check the Lean sources with Lean 4.29.1 and Mathlib commit `5e932f97dd25535344f80f9dd8da3aab83df0fe6`.
